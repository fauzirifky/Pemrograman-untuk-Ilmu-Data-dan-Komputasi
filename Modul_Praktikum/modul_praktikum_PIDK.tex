\chapter{Praktikum 1: Python Dasar dan Alur Logika}
\begin{tujuanbox}
Mahasiswa mampu membaca dan menulis ekspresi Python, membedakan tipe data dasar, melakukan konversi tipe, menggunakan percabangan dan perulangan, serta menelusuri perubahan nilai variabel selama program berjalan.
\end{tujuanbox}

\section{Tipe data dan operasi}
Empat tipe yang sering muncul pada awal perkuliahan adalah \kode{int}, \kode{float}, \kode{bool}, dan \kode{str}. Python menentukan perilaku operator berdasarkan tipe operand. Karena itu dua ekspresi yang tampak mirip dapat memiliki arti berbeda.

\begin{lstlisting}
print(1 + True)       # bool berperilaku seperti 0/1 pada aritmetika
print('1' + '0')      # konkatenasi string
print(int('1') + 0)   # konversi eksplisit
print(3 / 2)          # pembagian biasa
print(3 // 2)         # floor division
print(bool('0'))      # string tidak kosong -> True
\end{lstlisting}

\begin{idebox}{Prinsip membaca ekspresi}
Sebelum menjalankan kode, tentukan tipe setiap operand, arti operator untuk tipe tersebut, lalu prediksi tipe dan nilai hasil. Jika operator tidak didefinisikan untuk pasangan tipe itu, prediksi error.
\end{idebox}

\section{Percabangan sebagai representasi kondisi matematika}
Untuk persamaan kuadrat $ax^2+bx+c=0$, diskriminan $D=b^2-4ac$ menentukan jenis akar. Struktur \kode{if}-\kode{elif}-\kode{else} menerjemahkan kondisi matematika tersebut menjadi alur program.

\begin{lstlisting}
a, b, c = 1.0, -3.0, 2.0
D = b**2 - 4*a*c

if D > 0:
    jenis = "dua akar real"
elif D == 0:
    jenis = "akar real kembar"
else:
    jenis = "akar kompleks"

print(D, jenis)
\end{lstlisting}

\section{Perulangan}
\kode{for} cocok ketika himpunan nilai yang akan dilalui sudah jelas. \kode{while} cocok ketika pengulangan bergantung pada kondisi yang berubah selama program berjalan.

\begin{lstlisting}
data = [3, -2, 0, 7, -5, 4, 9]
total_positif = 0

for x in data:
    if x > 0:
        total_positif += x

print(total_positif)
\end{lstlisting}

\section{None, break, dan continue}
\kode{None} dapat dipakai untuk menyatakan bahwa sebuah nilai tidak tersedia. Ini berbeda dari nol atau nilai ekstrem. \kode{continue} melewati sisa langkah pada iterasi saat ini, sedangkan \kode{break} menghentikan loop.

\begin{lstlisting}
data = [2.5, None, -1.0, 4.2, None, 100.0, 3.1]
valid = []

for x in data:
    if x is None:
        continue
    if abs(x) > 50:
        break
    valid.append(x)

print(valid)
\end{lstlisting}

\section{Loop bersarang}
Loop bersarang diperlukan ketika proses memiliki dua indeks, misalnya membentuk tabel, pola karakter, atau matriks sederhana.

\begin{lstlisting}
n = 5
for i in range(1, n + 1):
    for j in range(i):
        print('*', end='')
    print()
\end{lstlisting}
Jumlah karakter yang dicetak adalah $1+2+\cdots+n=n(n+1)/2$.

\chapter{Praktikum 2: Fungsi, Subprogram, dan Rekursi}
\begin{tujuanbox}
Mahasiswa mampu mendefinisikan fungsi dengan parameter dan nilai balik, memahami scope, menggunakan tuple/unpacking, menyusun fungsi dari fungsi lain, memperlakukan fungsi sebagai objek, serta mengenali struktur dasar rekursi.
\end{tujuanbox}

\section{Subprogram dan fungsi}
Subprogram adalah bagian program yang diberi nama dan menjalankan tugas tertentu. Pada Python, fungsi yang dibuat dengan \kode{def} merupakan bentuk subprogram yang paling umum. Fungsi membantu memisahkan persoalan besar menjadi unit yang dapat dipanggil, diuji, dan digunakan kembali.

\begin{lstlisting}
def polinom_sederhana(x):
    return 2 - 3*x + x**2

print(polinom_sederhana(4))
\end{lstlisting}
Dalam definisi di atas, \kode{x} adalah parameter. Pada pemanggilan \kode{polinom_sederhana(4)}, nilai \kode{4} adalah argumen.

\section{Empat bentuk fungsi}
Secara dasar fungsi dapat dibedakan berdasarkan ada tidaknya argumen dan ada tidaknya nilai balik.
\begin{tabularx}{\textwidth}{@{}p{0.24\textwidth}p{0.35\textwidth}X@{}}
\toprule
Bentuk & Contoh & Makna \\
\midrule
Tanpa argumen, tanpa return & \kode{def salam(): print('Halo')} & melakukan aksi \\
Tanpa argumen, dengan return & \kode{def pi(): return 3.14159} & menghasilkan nilai tetap \\
Dengan argumen, tanpa return & \kode{def tampil(x): print(x)} & menerima input lalu menampilkan \\
Dengan argumen, dengan return & \kode{def f(x): return x**2} & menghasilkan nilai untuk dipakai kembali \\
\bottomrule
\end{tabularx}

\section{print, return, dan None}
\begin{lstlisting}
def g(x):
    return x**2 - 1

def h(x):
    print(g(x))

y = h(3)
print(y)
\end{lstlisting}
\kode{print} hanya menampilkan nilai. Jika fungsi tidak mencapai \kode{return}, Python mengembalikan \kode{None}. Karena itu hasil fungsi seperti \kode{h} tidak langsung dapat dipakai dalam operasi aritmetika.

\section{Multiple return, tuple, dan unpacking}
\begin{lstlisting}
def stat_ringkas(a, b, c, d):
    nilai = [a, b, c, d]
    minimum = min(nilai)
    maksimum = max(nilai)
    rata = sum(nilai) / len(nilai)
    rentang = maksimum - minimum
    return minimum, maksimum, rata, rentang

mn, mx, r, rg = stat_ringkas(4, 7, 1, 9)
\end{lstlisting}
Python sebenarnya mengembalikan satu tuple. Unpacking menempatkan elemen tuple ke beberapa variabel.

\section{Scope lokal dan global}
\begin{lstlisting}
x = 10

def f(a):
    x = a + 2
    return x

print(f(5))
print(x)
\end{lstlisting}
Variabel \kode{x} di dalam fungsi bersifat lokal. Untuk program komputasi, fungsi yang menerima input dan mengembalikan output secara eksplisit biasanya lebih mudah diuji daripada fungsi yang mengubah banyak variabel global.

\section{Komposisi dan fungsi sebagai objek}
Jika $(f\circ g)(x)=f(g(x))$, maka pola yang sama dapat ditulis sebagai fungsi yang memanggil fungsi lain.
\begin{lstlisting}
def proses(x, f):
    return f(x)

def kuadrat(x):
    return x**2

print(proses(5, kuadrat))
\end{lstlisting}
Nama \kode{kuadrat} tanpa tanda kurung adalah objek fungsi dan dapat dikirim sebagai argumen.

\section{Lambda}
Lambda sesuai untuk fungsi pendek yang hanya terdiri dari satu ekspresi.
\begin{lstlisting}
f = lambda x: 3*x**2 - 2*x + 1
print(f(2))
\end{lstlisting}
Jika logika mulai panjang, gunakan fungsi bernama dengan \kode{def}.

\section{Rekursi dasar}
Rekursi terjadi ketika fungsi memanggil dirinya sendiri. Dua komponen wajib adalah \textit{base case} dan langkah yang membawa masalah lebih dekat ke base case.

Untuk faktorial,
\[
0!=1,\qquad n!=n(n-1)!,\quad n\ge1.
\]
\begin{lstlisting}
def faktorial(n):
    if n == 0:
        return 1
    return n * faktorial(n - 1)
\end{lstlisting}
Untuk $n=4$, urutan pemanggilan adalah $4\to3\to2\to1\to0$, lalu nilai dikembalikan ke arah sebaliknya.

\begin{latihanbox}{Latihan Praktikum 2}
\begin{enumerate}
  \item Buat masing-masing satu contoh untuk empat bentuk fungsi pada tabel di atas.
  \item Tulis \kode{polinom(x, koef)} untuk $p(x)=a_0+a_1x+\cdots+a_nx^n$ tanpa \kode{numpy.polyval}.
  \item Buat \kode{stat_ringkas(a,b,c,d)} yang mengembalikan minimum, maksimum, rata-rata, dan rentang. Lakukan unpacking.

\section{Ukuran input dan orde pertumbuhan}
Big-O menggambarkan bagaimana kebutuhan komputasi tumbuh ketika ukuran input $n$ membesar. Urutan umum:
\[
1 \prec \log n \prec n \prec n\log n \prec n^2 \prec n^3 \prec 2^n \prec n!.
\]

\section{Menghitung operasi dari struktur loop}
\begin{lstlisting}

        kerja()
\end{lstlisting}
Baris \kode{kerja()} dieksekusi $n^2$ kali, sehingga orde pertumbuhan adalah $O(n^2)$.

Dua loop berurutan masing-masing $O(n)$ menghasilkan $O(n)+O(n)=O(n)$, bukan $O(n^2)$.

\section{Loop yang membagi dua}
\begin{lstlisting}

while i > 0:
    i = i // 2
\end{lstlisting}
Jumlah iterasi sebanding dengan $\log_2 n$.

\section{Sorting dasar}
Selection sort memilih elemen minimum dari bagian yang belum terurut dan menempatkannya di posisi berikutnya. Insertion sort menyisipkan elemen ke bagian kiri yang sudah terurut. Bubble sort melakukan pertukaran elemen bertetangga.

\begin{lstlisting}
def selection_sort(data):
    a = data.copy()
    n = len(a)
    for i in range(n - 1):
        k = i
        for j in range(i + 1, n):
            if a[j] < a[k]:
                k = j
        a[i], a[k] = a[k], a[i]
    return a
\end{lstlisting}

\section{Sequential dan binary search}
Sequential search memeriksa elemen satu per satu. Binary search memanfaatkan keterurutan data dan mengurangi interval pencarian sekitar setengah pada setiap langkah.

\begin{lstlisting}
def binary_search(a, target):
    kiri, kanan = 0, len(a) - 1
    while kiri <= kanan:
        tengah = (kiri + kanan) // 2
        if a[tengah] == target:
            return tengah
        if a[tengah] < target:
            kiri = tengah + 1
        else:
            kanan = tengah - 1
    return -1
\end{lstlisting}

\section{Tracing binary search}
Untuk list terurut \kode{[3,5,6,8,11,12,14,15,17,18]}, catat pada setiap langkah: indeks kiri, kanan, tengah, nilai tengah, dan keputusan berikutnya. Tracing menjelaskan mengapa kompleksitas binary search adalah $O(\log n)$.

\chapter{Praktikum 7: Aljabar Linier Komputasional}
\begin{tujuanbox}
Mahasiswa mampu merepresentasikan vektor dan matriks, membedakan operasi element-wise dan perkalian matriks, menghitung transpose dan invers, menyelesaikan SPL, memeriksa residual, menghitung norma dan nilai eigen, serta melihat data sebagai matriks.
\end{tujuanbox}

\section{Vektor: list dan array}
List Python adalah struktur umum. NumPy array dirancang untuk komputasi numerik dan mendukung operasi vektor secara langsung.
\begin{lstlisting}
import numpy as np
x = np.array([1., -2., 3.])
y = np.array([4., 0., -1.])
print(x + y)
print(np.dot(x, y))
print(np.linalg.norm(x))
\end{lstlisting}

\section{Element-wise dan matrix multiplication}
Untuk array NumPy, \kode{A*B} berarti perkalian elemen yang bersesuaian, sedangkan \kode{A@B} berarti perkalian matriks.

\section{Perkalian matriks manual}
Untuk memahami definisi $C=AB$ dengan $c_{ij}=\sum_k a_{ik}b_{kj}$, implementasikan perkalian matriks dengan tiga loop sebelum memakai \kode{@}.

\section{Transpose dan invers}
Untuk $A\in\R^{m\times n}$, transpose memiliki ukuran $n\times m$. Untuk
\[
A=\begin{pmatrix}a&b\\c&d\end{pmatrix},\qquad
A^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix},
\]
selama $ad-bc\neq0$.

\section{Sistem persamaan linier dan residual}
Untuk $Ax=b$, solusi numerik $\hat{x}$ perlu diperiksa melalui residual
\[
r=b-A\hat{x},\qquad \|r\|_2.
\]
\begin{lstlisting}
A = np.array([[2., 1.], [5., 3.]])
b = np.array([1., 4.])
x = np.linalg.solve(A, b)
r = b - A @ x
print(x, np.linalg.norm(r))
\end{lstlisting}

\section{Nilai eigen}
Pasangan $(\lambda,v)$ memenuhi $Av=\lambda v$. Setelah memperoleh hasil dari \kode{np.linalg.eig}, verifikasi numerik dengan norma $\|Av-\lambda v\|_2$.

\section{Data sebagai matriks}

\chapter{Praktikum 8: Regresi Linear Berbasis Aljabar Linier}
\begin{tujuanbox}
Mahasiswa mampu membentuk matriks desain, menghitung parameter least squares sederhana, membuat prediksi, menghitung residual, dan memvisualisasikan hasil regresi.
\end{tujuanbox}

Untuk model $y_i=\beta_0+\beta_1x_i+\varepsilon_i$, bentuk matriks
\[
y=X\beta+\varepsilon,
\]
dan cari $\beta$ melalui persamaan normal $(X^TX)\beta=X^Ty$ untuk tujuan pembelajaran aljabar linier.

\begin{lstlisting}
import numpy as np

x = np.array([1., 2., 3., 4., 5.])
y = np.array([2.1, 3.9, 6.2, 8.0, 10.1])
X = np.column_stack([np.ones(len(x)), x])
beta = np.linalg.solve(X.T @ X, X.T @ y)
yhat = X @ beta
residual = y - yhat
print(beta)
print(np.linalg.norm(residual))
\end{lstlisting}
