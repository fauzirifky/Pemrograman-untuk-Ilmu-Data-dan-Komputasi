# Modul Praktikum PIDK

Folder ini memuat modul praktikum mata kuliah **Pemrograman untuk Ilmu Data dan Komputasi (MA25-21008)**.

- `modul_praktikum_PIDK.tex`: source LaTeX.
- `modul_praktikum_PIDK.pdf`: hasil kompilasi.
- `itera_logo.png`: logo untuk cover, bila tersedia.

Compile lokal:

```bash
cd Modul_Praktikum
pdflatex -interaction=nonstopmode -halt-on-error modul_praktikum_PIDK.tex
pdflatex -interaction=nonstopmode -halt-on-error modul_praktikum_PIDK.tex
```

Modul mencakup Praktikum 1-7 sebagai fondasi sampai UTS, latihan terpadu UTS, serta Praktikum 8-10 setelah UTS.
